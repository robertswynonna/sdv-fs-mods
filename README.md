# Goldilocks.exe's Fashion Sense Mods

Clothing and accessory content packs for [Stardew Valley](https://www.stardewvalley.net/), made for [Fashion Sense](https://www.nexusmods.com/stardewvalley/mods/9969).

> **Looking to download?** Grab the mods from Nexus using the links below. This repo holds the source files and version history.

## Requirements

- [SMAPI](https://smapi.io/)
- [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915)
- [Fashion Sense](https://www.nexusmods.com/stardewvalley/mods/9969)

## Installation

1. Install SMAPI, Content Patcher, and Fashion Sense according to their pages' installation instructions.
2. Download one of my mods from their Nexus page.
3. Unzip it into your `Stardew Valley/Mods` folder or install with a mod manager like Vortex.
4. Launch the game through SMAPI and use the Fashion Sense hand mirror to find the new items.

## Repo layout

Each `[FS] ...` folder is one complete, self-contained mod. `_source-art/` holds working art files and is not part of any release.
